# PiFlex Browser — Implementation Plan

See `docs/ARCHITECTURE.md` for the full design. This plan tracks the phased delivery of features.

## Phases

1. Core shell (tabs, navigation, bookmarks, history)
2. Privacy layer (adblock, permissions, private session)
3. Data layer (SQLite, autofill, passwords, downloads)
4. Extensions support
5. On-device AI assistant (llama.cpp, GGUF models)
6. Polish (new tab, wallpapers, diagnostics, help)

## Status

All phases through 6 are implemented in v2.0.0. See `CHANGELOG.md` for release notes.
